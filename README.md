# Patrimonio OS Arriendos

Aplicación Angular 21 para gestión de arriendos inmobiliarios con almacenamiento en `localStorage`, tema dark/light, Angular Material, Tailwind CSS 4 y despliegue en GitHub Pages.

## Scripts principales

```bash
npm start
npm run build
npm test
npm run build:gh
npm run deploy
```

## Módulos incluidos

- Dashboard con resumen mensual, alertas y accesos rápidos
- Inmuebles con listado, detalle, formulario y cambio rápido de estado
- Contratos con wizard de 3 pasos, IPC y detalle de pagos
- Pagos con agrupación mensual y notificaciones por WhatsApp
- Mantenimientos con filtros, costos y actualización de estado

## Stack

- Angular 21 standalone + zoneless
- TypeScript estricto
- Signals + stores con `@ngrx/signals`
- Angular Material 21
- Tailwind CSS 4
- Locale `es-CO`
